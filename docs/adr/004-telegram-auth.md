# ADR-004: Авторизация Telegram по числовому user ID

## Статус
Принято

## Контекст
Telegram-бот предоставляет полный доступ к файловой системе и инструментам
сборки в контейнере. Необходимо гарантировать, что доступ есть только
у владельца.

## Решение
Авторизация строго по числовому `ALLOWED_TELEGRAM_ID` (integer).
Сообщения от любых других user ID — молча игнорируются.

**Запрещено** использовать `@username` для авторизации:
- Username можно сменить (identity rebinding, GHSA-mj5r-hh7j-4gxf).
- Username можно перехватить после смены владельцем.

## Альтернативы
- **По @username:** небезопасно (описано выше).
- **Пароль в чате:** неудобно, видно в истории Telegram.
- **Whitelist нескольких ID:** возможно в будущем, но пока один пользователь.

## Последствия
- ✅ Надёжная идентификация — user ID неизменяем.
- ✅ Простая реализация — одна проверка в middleware.
- ⚠️ Для добавления второго пользователя — изменить env и перезапустить.
