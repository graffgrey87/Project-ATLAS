# ADR-003: Qwen3.6-35B-A3B с адаптивной квантизацией

## Статус
Принято

## Контекст
Нужна VLM (Vision Language Model) с поддержкой Function Calling, работающая
на GPU от 48 ГБ суммарной VRAM. Модель должна автоматически подбираться
под архитектуру чипа.

## Решение
Qwen3.6-35B-A3B (MoE: 35B total / 3B active) с двумя вариантами квантизации:

| GPU архитектура | Compute Cap | Модель | Размер весов |
|-----------------|-------------|--------|-------------|
| Ada / Hopper / Blackwell | ≥ 8.9 | Qwen/Qwen3.6-35B-A3B-FP8 | ~33.5 ГБ |
| Ampere | < 8.9 | QuantTrio/Qwen3.6-35B-A3B-AWQ | ~25 ГБ |

FP8-версия использует `--kv-cache-dtype fp8` для экономии VRAM.
AWQ-версия использует стандартный KV-кэш (fp8 не поддерживается на Ampere).

## Альтернативы
- **Qwen3-30B-A3B:** предыдущее поколение, слабее в vision-задачах.
- **DeepSeek-V3:** слишком большая для 48 ГБ даже в квантизации.
- **Llama-4-Scout:** хороший вариант, но слабее в function calling.

## Последствия
- ✅ Единая модель для текста, vision и function calling.
- ✅ MoE архитектура — быстрый инференс при 3B активных параметрах.
- ✅ Автоматический выбор квантизации без участия пользователя.
- ⚠️ AWQ-версия от сообщества (QuantTrio) — не официальная.
