# ADR-006: Базовый образ и версии vLLM/PyTorch

## Статус
Принято

## Контекст
Сборка в CI падала: тег `runpod/pytorch:1.0.3-cu1300-torch2130-ubuntu2404` не существует;
`vllm>=0.28.0` без верхней границы ставил 0.33.0, требующий `torch==2.14.0`,
тогда как базовый образ содержит torch 2.13.0.

## Решение
- Базовый образ: `runpod/pytorch:2.2.0-rc.229-cu1300-torch2130-ubuntu2404` (проверен на Docker Hub).
- vLLM: `>=0.28.0,<0.33.0` (0.28-0.32 требуют `torch==2.13.0`).
- Версия torch из образа записывается в pip-constraint, чтобы pip её не подменял.

## Альтернативы
- Multi-stage / два контейнера — отложены как fallback.
- Обновление torch до 2.14 — отклонено: ломает совместимость с CUDA 13.0 из образа.

## Последствия
- Сборка воспроизводима; конфликт виден сразу, а не при запуске на RunPod.
- Тег `rc` может быть заменён RunPod — периодически сверять с Docker Hub.
- Решение проверено анализом метаданных PyPI, но не успешной сборкой (на 2026-11-15).
