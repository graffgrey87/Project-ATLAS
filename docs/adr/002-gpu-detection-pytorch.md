# ADR-002: Определение GPU через PyTorch

## Статус
Принято

## Контекст
Entrypoint должен автоматически определять количество GPU, их архитектуру
и объём VRAM для выбора модели и параметров vLLM.

В контейнерах RunPod `nvidia-smi` может показывать все GPU физического хоста
(а не только выделенные контейнеру), что приводит к неверному
`--tensor-parallel-size` и краху NCCL.

## Решение
Использовать inline Python-скрипт на базе PyTorch:
- `torch.cuda.device_count()` — видит только выделенные карты.
- `torch.cuda.get_device_capability(i)` — compute capability.
- `torch.cuda.mem_get_info(i)` — доступная и общая VRAM.

## Альтернативы
- **nvidia-smi:** ненадёжен в контейнерах RunPod (видит хост).
- **pynvml:** ближе к драйверу, но тоже может видеть хост без
  `NVIDIA_VISIBLE_DEVICES`. PyTorch уже учитывает эту переменную.

## Последствия
- ✅ Надёжное определение только выделенных GPU.
- ✅ PyTorch уже установлен в базовом образе — нулевые доп. зависимости.
- ⚠️ Требуется корректная инициализация CUDA (первый вызов может занять 2-3 сек).
