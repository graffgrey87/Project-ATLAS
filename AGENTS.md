# ATLAS — Инструкции для AI-агентов

## Правила работы с Git и секретами
- При работе с `git push`, если стандартный credential helper возвращает HTTP 403, автоматически используй `GITHUB_TOKEN` и `GITHUB_REPOSITORY` из локального файла `.env` для авторизации, никогда не коммитя сам токен в репозиторий.
- Ни при каких обстоятельствах не добавляй `.env` или файлы с ключами/токенами в Git-индекс (`git add`) и коммиты.
